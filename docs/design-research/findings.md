## 3. Recurring Patterns Across `>= 3` Products (`STEP 0.5.3`)

1. **Dual-Mode MCQ Answer Controls: 4 Large `A`–`D` Selector Buttons for Image Questions vs. Full-Row Options for Text-Only Questions** (`[DOC]` in SAT Bluebook `R5` `https://satsuite.collegeboard.org/digital/digital-testing/practice-preparation`, Canvas New Quizzes `R1` `https://community.canvaslms.com/t5/Student-Guide/tkb-p/student#Quizzes`, TAO Advance `R3` `https://userguide.taotesting.com/`; `[GENERAL]` in Khan Academy `R6` and PDF-crop assessment tools):
   - **Image-based questions (`hasImage === true`, where options `A`–`D` are embedded inside the 200 DPI PDF crop):** Do NOT render redundant full-width text rows (`"Option A"`, `"Option B"`, ...). Instead, render **four large `A`–`D` selector buttons** (`min-height: 56px`; 1 row `grid-cols-4` on desktop, `2x2` `grid-cols-2` on narrow screens) inside a native `<fieldset>` + `<legend>` radio group with `A`–`D` keyboard shortcuts. When selected, the button uses the neutral slate-ink selected tokens (`--selected-border: #0f172a`, `--selected-bg: #f1f5f9`), a solid badge (`--selected-badge-bg: #0f172a`), and a check icon + `"Selected"` text so selection never looks like an error.
   - **Text-only fallback questions (`!hasImage`):** Render full-width bordered option rows (`min-height: 52–56px`, constrained to `60–70ch` line length) with a circular `A`–`D` badge on the left and check icon + `"Selected"` label on the right.
2. **Dedicated Distraction-Free `FocusLayout` for Active Attempts** (`[SEEN]` in `04-sat-bluebook.png`; `[DOC]` in Inspera `R2` `https://support.inspera.com/`, TAO Advance `R3` `https://userguide.taotesting.com/`, Canvas New Quizzes `R1` `https://community.canvaslms.com/t5/Student-Guide/tkb-p/student#Quizzes`):
   - Global app navigation, sidebars, and marketing footers are removed during an active sitting. A compact `56px` sticky top bar holds only the exam title, autosave status, countdown timer, and submit trigger.
3. **Calm Authoritative Timer with Separated Threshold Colors, Icon & `aria-live`** (`[DOC]` in SAT Bluebook `R5` `https://satsuite.collegeboard.org/digital/digital-testing/practice-preparation`, Inspera `R2` `https://support.inspera.com/`, Canvas `R1` `https://community.canvaslms.com/t5/Student-Guide/tkb-p/student#Quizzes`; `[GENERAL]` in Moodle `R4`):
   - Uses `font-variant-numeric: tabular-nums` so digits never jitter horizontally:
     - **Normal (`> 5 minutes`):** Neutral surface (`--bg-subtle`), primary ink (`--text-primary`), clock icon.
     - **Warning (`<= 5 minutes`):** Amber warning surface (`--warning-subtle`), amber border (`--warning-border`), amber text (`--warning: #92400e`), warning icon, and a single polite `aria-live="polite"` announcement at the `5m` boundary.
     - **Danger / Critical (`<= 1 minute`):** Uses the **separated danger color** (`--danger: #c2250a` on `--danger-subtle: #fff4f1` with `--danger-border: #f9b4a6`, visually distinct from brand crimson `--accent-primary: #9f1239`), paired with an alert icon and an `aria-live="assertive"` announcement at `1m` and `0s`.
4. **Pre-Exam Specification Grid Before Timer Launch** (`[DOC]` in Canvas New Quizzes `R1` `https://community.canvaslms.com/t5/Student-Guide/tkb-p/student#Quizzes`, Inspera `R2` `https://support.inspera.com/`, SAT Bluebook `R5` `https://satsuite.collegeboard.org/digital/digital-testing/practice-preparation`; `[GENERAL]` in Moodle `R4`):
   - Displays `Duration`, `Questions`, `Pass Mark`, and `Attempts` in a structured summary grid above sitting instructions and a single primary `Start` / `Resume` CTA.
5. **Admin Left Sidebar (`240px`) + Segmented Filter Bar + Dense Tabular-Nums Table** (`[SEEN]` in `06-stripe-dashboard-docs.png` and `07-linear-interface.png`; `[DOC]` in Gradescope `R7` `https://guides.turnitin.com/hc/en-us/categories/22820996401165-Gradescope`):
   - Admin routes use a persistent `240px` left sidebar on desktop (`>= 1024px`) and a clean `<PageHeader>` instead of oversized dark marketing banners.
6. **Side-by-Side PDF Crop Preview & Question Metadata Controls** (`[DOC]` in Gradescope `R7` `https://guides.turnitin.com/hc/en-us/categories/22820996401165-Gradescope`):
   - PDF question import pairs each cropped region image with its question number, point value, answer key (`A`–`D`), and crop adjustment controls.

## 4. Pitfalls to Avoid (`STEP 0.5.3`)

1. **Oversized Dark Gradient Hero Banners in Logged-In Workspaces** (Observed in our current `StudentDashboardPage` and `AdminOverviewPage` `before` screenshots): Replace `.portal-hero*` dark gradients with `<PageHeader>` + `StatCard` strip.
2. **Color-Only Status Encoding:** Always pair semantic status colors with icons and text labels (`✓ Passed`, `✕ Did not pass`, `✕ Incorrect`, `● Published`).
3. **Shrinking 200 DPI Full-Width PDF Question Crops Into a Narrow Card (`[GENERAL]` + Verified in `design-direction.md` Section 5):** A `760px` card shrinks a `1500px`-wide 200 DPI full-page PDF crop to `~0.47x` (`~13px` effective text height). Widening the desktop question card to `920px` inside a `1280px` container keeps `10pt` PDF text at `~16–18px` without zooming, while adding tap-to-zoom for mobile/detailed inspection.
4. **Anxiety-Inducing Timer Animations:** Never flash or pulse the timer every second.
5. **Ad-Hoc Raw HTML Inputs Inside Editors:** Replace raw `<input type="number" className="w-20 rounded border p-2">` in `BulkParserPanel.tsx` and `QuestionListEditor.tsx` with token-backed primitives.
6. **Visual Divergence Between Admin and Student UIs:** The administrator and student interfaces must not look like two different products; both must share the exact same semantic CSS tokens (`--bg-*`, `--text-*`, `--border-*`, `--accent-*`, `--danger-*`), typography scale, radius/shadow system, and core UI primitives (`<PageHeader>`, `Card`, `StatCard`, `StatusPill`, `Button`, `Dialog`, `ResponsiveTable`), differing only in layout shell (`AdminLayout` sidebar vs. `StudentLayout` top bar / `FocusLayout`).

## 5. Accessibility Conventions (`STEP 0.5.3`)

- **Skip Link & Programmatic `<h1>` Focus on Route Change** (`[DOC]` TAO Advance `R3`, Canvas `R1`).
- **Native `<fieldset>` + `<legend>` + Radio Group Keyboard Navigation** (`[DOC]` TAO Advance `R3`, SAT Bluebook `R5`).
- **Polite (`5m`) & Assertive (`1m`, `0s`) `aria-live` Timer Announcements** (`[DOC]` SAT Bluebook `R5`, `[GENERAL]` Moodle `R4`).
- **Native `<dialog>.showModal()` Focus Trapping, Focus Restoration & Safe Initial Focus** (`Cancel` focused by default in destructive `ConfirmDialog`).
